# [ARO-003] ✅ DONE - Repair or retire `molecule/default`

**Status**: Done (2026-10-18)
**Priority**: Medium
**Component**: `molecule/default/`

**Summary**:
As the role maintainer, I want the default molecule scenario to either prove
something or be gone, so that a green test run is evidence rather than noise.

**Description**:
`molecule/default` is vestigial and currently proves nothing:

- `verify.yml` is a single `assert: that: true`.
- `hosts` names the original author's sites (`berlin_*`, `szczecin_*`) and hosts
  that do not exist in this scenario.
- `prepare.yml` carries unfinished TODOs and depends on the
  `weareinteractive.apt` / `weareinteractive.users` galaxy roles.
- `converge.yml` includes the whole role, which starts the openHAB container and
  therefore needs docker-in-docker.

A scenario that always passes is worse than no scenario: it invites the claim
that the role is tested. [ARO-002](aro-002.md) sidestepped it entirely with a
focused `git-seeding` scenario rather than repairing this one, which was right
for that change and leaves the question open.

The honest choice is between repairing it into a real full-role test — which
means solving docker-in-docker for the container task — and deleting it in
favour of focused scenarios per concern. Deleting is cheaper and matches how
`git-seeding` is built; repairing is the only way to ever test the container
task itself.

**Decision** (2026-10-18): **retire.** Repairing means docker-in-docker and
an openHAB image in every test run, to cover the one task the release-candidate
step already verifies on a real host — the container start. Focused scenarios,
one per concern, are what `git-seeding` already is; a green run then means
something. A future scenario for the container task is a new focused scenario,
not a repair of this one.

**Acceptance Criteria**:
- [x] A decision is recorded: repair or retire, with the reasoning.
- [x] If retired: `molecule/default` is removed and `AGENTS.md`'s reference to
      it drops with it.
- [x] ~~If repaired:~~ not applicable — it converges the whole role, asserts something that would
      fail if the role broke, and drops the stale inventory and galaxy deps.
- [x] No scenario in the repo passes without asserting anything.

**Out of scope**:
- CI wiring — [ARO-004](aro-004.md).
